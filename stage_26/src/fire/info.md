# Arduino Flash-Informationen

## Setup

Das Flashen geschieht über die Arduino IDE:

- Board auswählen: `Tools -> Board -> Arduino Nano`
- Korrekten Bootloader auswählen: `Tools -> Processor -> 'ATMega328P (Old Bootloader)`

## Flashen

- Arduino per USB verbinden
- Über `Tools -> Port` richtigen USB-Port auswählen
- ggf. Änderungen am Quelltext vornehmen
- ggf. per `Strg + R` kompilieren (alternativ über `✓`-Button oben links)
- per `Strg + U` Arduino flashen (alternativ über `→`-Button oben links)
